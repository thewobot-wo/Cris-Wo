# Cris Wo

A minimalist web page featuring a subtle shimmer effect on hover.

## Features

- Pure black background
- Centered white text with modern, thin typography
- Subtle light reflection shimmer effect on hover
- Responsive design
- Cross-browser compatible

## Usage

Simply open `index.html` in any modern web browser to view the page.

## Technologies

- HTML5
- CSS3 (with animations and gradients)
- Modern web standards
